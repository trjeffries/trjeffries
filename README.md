### Interactive Projects

| Name | Project Description | Tools | Link |
| -- | -- | -- | -- |
| Oh I LOVED That Song! | A game where the user guesses YouTube views of pre-YouTube number 1 songs, with built-in hints, stats and a streak counter. | Alteryx, Tableau | [Tableau Public](https://public.tableau.com/app/profile/tim.jeffries/viz/OhILOVEDThatSong/Dashboard1_1 "Oh I LOVED That Song! on Tableau Public") |
